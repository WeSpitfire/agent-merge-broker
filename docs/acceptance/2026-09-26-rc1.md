## Still required before `1.0.0`

- `agent-merge-broker-core` is **not published to npm**. The optional core
  publishing job was skipped. A maintainer must bootstrap it from the verified
  core artifact, configure its own trusted publisher, and verify its npm
  availability, `next` tag, package bytes, and provenance. Do not advertise
  registry installation of core until that is complete.
- A live, disposable protected GitHub repository trial must exercise two workers,
  rejection and correction, exact-candidate approval, protected publication and
  merge, and crash/restart reconciliation on this RC. It requires explicit
  repository and credential permission; local fake-forge tests do not replace it.
- An independent adopter must follow the published guide on the exact RC without
  implementation help and return a completed
  [walkthrough record](ADOPTER-TRIAL.md) with evidence links. The implementer's
  tests cannot self-certify this item.
- The installed-package upgrade rehearsal used idle registered tasks. It did not
  prove a safe upgrade during an in-flight legacy publication, older-than-`0.12.0`
  data, old signing keys, or compressed historical archives. Follow the documented
  drain and full-runtime backup procedure before upgrades.

Do not promote the RC or point npm `latest` at a 1.0 version while these required
acceptance items remain open. If the exact candidate changes, repeat the affected
checks and record a new candidate rather than editing the published tag.
